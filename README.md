# منصة تعلّم الآلة التفاعلية — Machine Learning من الصفر

منصة تعليمية بالعربية (واجهة RTL، السايد بار على اليمين) تشرح مشروع تعلّم الآلة
كاملًا للمبتدئين بلا خلفية في الرياضيات أو الإحصاء: شرح نظري + صيغ رياضية مفسَّرة
رمزًا رمزًا + رسوم تفاعلية ومتحرّكة + مشروع كامل منفَّذ خطوة بخطوة.

**إعداد: د. مروان رودان — Dr Merwan Roudane**

## التشغيل

```bash
pip install -r requirements.txt
streamlit run streamlit_app.py
```

أو بالنقر المزدوج على `run.bat` في ويندوز.

## محتوى المنصة (18 صفحة)

| القسم | الصفحات |
|---|---|
| الأساسيات | ما هو تعلّم الآلة؟ · أنواع التعلّم · خريطة المشروع الكاملة |
| البيانات | فهم البيانات وتنظيفها · هندسة المتغيّرات والتقييس · التقسيم والتحقّق المتقاطع |
| قلب التعلّم | الموديل والخوارزمية والمعاملات · دالة الخسارة والتكلفة · الانحدار التدريجي · حلقة التدريب |
| جودة التعلّم | الإفراط والتقصير · مقايضة التحيّز والتباين · التنظيم |
| التقييم | معايير الانحدار · معايير التصنيف · ضبط الهايبرباراميترز |
| التطبيق | مشروع كامل خطوة بخطوة · قاموس المصطلحات والمراجع |

## بنية المشروع

```
streamlit_app.py        # نقطة الدخول والتنقّل (st.navigation)
.streamlit/config.toml  # الثيم الفاتح والخطوط والألوان
lib/ui.py               # مساعدات مشتركة: RTL، البطاقات، ألوان الرسوم
app_pages/p01…p18.py    # صفحات المحتوى
```

## التخصيص

- **الألوان والخطوط:** عدّل `.streamlit/config.toml` فقط.
- **تنسيقات RTL والبطاقات:** في `lib/ui.py` داخل متغيّر `_CSS`.
- **إضافة صفحة:** أنشئ ملفًا في `app_pages/` وسجّله في قائمة `pages` داخل `streamlit_app.py`.
